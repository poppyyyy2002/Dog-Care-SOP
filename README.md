# 🐾 新手狗狗照護全攻略 (Dog Care SOP)

歡迎來到狗狗照護手冊！本專案旨在透過 **TPM 的管理邏輯**，幫助第一次養狗的朋友建立標準化的照護流程。

---

### 1. 📋 入門準備清單 (Checklist)
在接狗狗回家前，請確認以下物資是否齊備：
- [ ] **飲食：** 幼犬/成犬飼料、不鏽鋼飲水盆。
- [ ] **睡眠：** 舒適的睡墊、圍欄（建立安全感）。
- [ ] **衛生：** 寵物尿墊、撿便袋、專用洗髮精。
- [ ] **醫療：** 附近 24H 獸醫診所的電話。
